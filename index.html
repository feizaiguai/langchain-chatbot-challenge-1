关于此项目

这是一个 LangChain 对话机器人 的前端演示项目。

它模拟了 LangChain + LLM 的对话流程，包括：

  • Prompt 模板管理与对话上下文构建
  • 多轮对话记忆（ConversationBufferMemory）
  • 基于关键词匹配的本地意图识别
  • 模拟流式输出的 Token 生成效果

所有逻辑均在浏览器本地运行，无需后端服务。
